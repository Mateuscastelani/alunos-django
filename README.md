# Projeto de Gerenciamento de Alunos (Django)

Este é um projeto inicial desenvolvido em Python com o framework Django para o gerenciamento de registros de alunos da Univesp. O sistema demonstra os conceitos fundamentais de arquitetura MTV (Model-Template-View) e interação com banco de dados através do ORM do Django.

## 💻 Sobre o Projeto

O objetivo principal deste projeto foi construir uma aplicação web funcional capaz de persistir e exibir dados em tela. Ele foi estruturado utilizando boas práticas de componentização do Django, separando as configurações globais do aplicativo de visualização (`website`).

**Funcionalidades Implementadas:**
* Mapeamento Objeto-Relacional (ORM) para criação de tabelas.
* Inserção de dados de alunos (Nome, Sobrenome, Matrícula) via Django Shell.
* Utilização de *Class-Based Views* (`ListView`) para otimização do código de busca.
* Renderização de dados dinâmicos em HTML utilizando a *Template Language* nativa do Django.
* Configuração e roteamento dinâmico de URLs.

## 🛠️ Tecnologias Utilizadas

* **Python 3.14**
* **Django 6.1**
* **SQLite** (Banco de dados padrão)
* **HTML5** (Templates)
